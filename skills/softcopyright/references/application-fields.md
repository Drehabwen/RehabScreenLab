# 申请表字段口径（按登记系统真实表单顺序）

字数上限以系统为准；括号内为我们的硬约束，`make_application_form.py` 会用断言卡住。

| # | 字段 | 填写要求 |
| --- | --- | --- |
| 1 | 软件全称 | 与代码页眉、说明书封面/页眉三处一致 |
| 2 | 软件简称 | 可选 |
| 3 | 版本号 | 首次登记 `V1.0`（全称与版本号分开填） |
| 4 | 软件分类 | 应用软件 / 系统软件 / 中间件 / 嵌入式软件 / 其他 |
| 5 | 开发完成日期 | `YYYY-MM-DD`，不得晚于申请日 |
| 6 | 开发方式 | **单独开发**（官方用词，不是"独立开发"）；合作/委托另附合同 |
| 7 | 软件说明 | 原创（修改/合成软件另选） |
| 8 | 发表状态 | 已发表 / 未发表 |
| 9 | 首次发表日期 | 已发表才填；未发表不填 |
| 10 | 著作权人 | 自然人：国家/省市/姓名/证件类型/证件号 |
| 11 | 权利取得方式 | 原始取得 |
| 12 | 权利范围 | 全部权利 / 部分权利 |
| 13 | 开发的硬件环境 | ≤50 字，实际开发机 |
| 14 | 运行的硬件环境 | ≤50 字，部署与终端 |
| 15 | 开发该软件的操作系统 | ≤50 字，如 `Windows 11` |
| 16 | 软件开发环境 / 开发工具 | ≤50 字，`开发环境: Windows 11/开发工具: Visual Studio Code`；**只写 IDE，不写框架** |
| 17 | 该软件的运行平台 / 操作系统 | ≤50 字 |
| 18 | 软件运行支撑环境 / 支持软件 | ≤50 字，运行时依赖，不加前缀 |
| 19 | 编程语言 | 预设按钮 + 自定义 ≤120 字 |
| 20 | 源程序量 | **纯数字**，全部源程序总行数（不写"行"） |
| 21 | 开发目的 | ≤50 字，不能只写软件名 |
| 22 | 面向领域 / 行业 | ≤50 字 |
| 23 | 软件的主要功能 | **500~1300 字**（写少了会被补正） |
| 24 | 软件的技术特点 | 标签多选（医疗软件/人工智能软件/APP/教育软件…）+ 文本 **≤100 字** |
| 25 | 页数 | **纯数字**，代码鉴别材料实际页数（60） |

## 一致性

- 软件全称、版本号、开发完成日期：申请表 == 代码页眉 == 说明书封面，三处必须完全一致。
- 源程序量 == 统计行数；页数 == 实际提交 PDF 页数。
- 交付前把 `【著作权人姓名】`、身份证号、省市、地址、邮箱等 ★ 项替换完再提交。
